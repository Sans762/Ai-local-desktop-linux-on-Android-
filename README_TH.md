# Local AI Native v0.3 — AI ออฟไลน์และ Remote Desktop ในแอป Android

## สิ่งที่ทำได้

- **ไม่ต้องใช้ Termux**: Android Native + Foreground Service + WebView และเว็บ Dashboard ในแอป
- **Native Workspace**: แชทด้วยโมเดล GGUF บนมือถือ (ต้องนำเข้าไฟล์โมเดลเอง), ประวัติ SQLite และตั้งชื่อ AI เอง
- **Control Center**: ตั้งรหัสผ่าน, นำเข้า GGUF / memory.db จากตัวเลือกไฟล์ Android, เปิด/ปิด AI และสิทธิ์ Accessibility
- **Remote Desktop (ทดลอง)**: ผู้ใช้ต้องแตะเริ่มแชร์และกดยืนยันสิทธิ์บันทึกหน้าจอ Android (MediaProjection), ดูจอสดผ่านเว็บบน LAN/VPN ส่วนตัว และจับคู่ด้วย PIN 8 หลัก
- **การควบคุมระยะไกล (ทดลอง)**: แตะหน้าจอ, Back, Home และพิมพ์ในช่องที่โฟกัสได้เมื่อเปิด **ทั้ง** การอนุญาตควบคุมในแอป, Accessibility, และอนุญาต Remote Input ในเซสชันนั้น ไม่แก้ช่องรหัสผ่าน
- ปิดการแชร์ในแอปหรือแจ้งเตือนระบบเพื่อยกเลิก token ทุกตัวทันที

## วิธีใช้ Remote Desktop

1. ติดตั้ง APK แล้วตั้งรหัสผ่านใน **Control Center** ก่อน
2. กด **เริ่มแชร์หน้าจอ (ต้องอนุญาต)** แล้วตอบตกลงที่หน้าต่าง Android
3. แอปจะแสดงลิงก์ IP วงส่วนตัว เช่น `http://192.168.x.x:18789` และ PIN 8 หลักสำหรับเซสชันนั้น
4. บนอีกเครื่องที่ต่อ Wi-Fi/LAN เดียวกันหรือ VPN ส่วนตัว เปิดลิงก์ในเบราว์เซอร์แล้วกรอก PIN
5. เริ่มต้นเป็น **View Only**; หากต้องการกดหน้าจอ ให้เปิด `อนุญาตให้ AI ส่งคำสั่ง…` + เปิด Accessibility + `อนุญาตให้รีโมทกดหน้าจอ` ในแอป
6. กด **หยุดแชร์หน้าจอ** เมื่อใช้งานเสร็จ การอนุญาตและ PIN จะถูกยกเลิก

## ความปลอดภัยและข้อจำกัดที่ต้องรู้

- เว็บรีโมทปัจจุบันเป็น **HTTP ไม่เข้ารหัส** ห้าม Forward Port 18789 ออกสู่อินเทอร์เน็ตหรือใช้ Wi-Fi สาธารณะ ใช้เฉพาะ LAN ที่เชื่อถือได้ หรืออยู่ภายใต้ VPN ส่วนตัวที่เข้ารหัสเท่านั้น
- โค้ดจำกัดผู้เชื่อมต่อเป็น private IPv4 และ CGNAT range; จับคู่ 8 หลักพร้อมจำกัดจำนวนครั้งที่เดาผิด, โทเคนสุ่มเก็บเฉพาะหน่วยความจำ, CSRF และ Origin guard; แต่ **ไม่เทียบเท่ากับ HTTPS/รีโมทอินเทอร์เน็ตที่ปลอดภัย**
- **ChatGPT ไม่สามารถเชื่อมเข้ามาควบคุมมือถือเองโดยอัตโนมัติจากลิงก์นี้** ต้องมี connector/remote-control integration ที่ได้รับอนุญาตและเชื่อมต่อจริง
- MediaProjection จะแชร์ส่วนของหน้าจอที่ Android อนุญาต และบางแอปที่ป้องกันภาพอาจแสดงเป็นจอดำ
- Android/OEM อาจหยุดบริการเบื้องหลังเมื่อ RAM ต่ำ ผู้ใช้ยังต้องอนุญาตแชร์จอใหม่ทุกครั้งเมื่อเริ่มเซสชัน
- โหมด Windows Remote, LINE, โทรเสียง และ autonomous AI Agent เต็มรูปแบบ **ยังไม่มี** อย่าตีความว่ารีโมท Android เท่ากับควบคุม Windows ได้ทันที
- การติดตั้ง APK แบบ Debug จาก GitHub ต่าง Workflow อาจใช้ signing key ต่างกัน ไม่สามารถอัปเดตทับแอปเก่าที่มีลายเซ็นไม่ตรงกันได้: **อย่าถอนการติดตั้งแอปเก่าก่อนสำรองข้อมูล**
