# Local AI Linux Desktop สำหรับ Android — v0.13

**แอป Android Native ที่รัน Alpine Linux และ AI ภายในเครื่อง ไม่ใช้ Termux ไม่ต้อง Root และไม่ควบคุมหน้าจอ Android**

> **[เปิดแผนการพัฒนา ระบบที่ยังขาด และเกณฑ์ทดสอบทั้งหมด](DEVELOPMENT_PLAN_TH.md)**

## อัปเดตอัตโนมัติ (เพิ่มโค้ดแล้วใน v0.13)
ระบบ Release จะตรวจเวอร์ชันใหม่บน Wi-Fi และดาวน์โหลดไฟล์ APK เอง พร้อมตรวจ SHA-256 และลายเซ็น ก่อนส่งแจ้งเตือนให้กดยืนยันติดตั้งจาก Android แต่ **ยังไม่มี APK Release ที่เซ็นคีย์ถาวร** จึงยังไม่สามารถเปิดใช้กับรุ่น TEST ที่ติดตั้งอยู่ได้ และ Android ไม่อนุญาตให้แอปทั่วไปติดตั้งเงียบ ๆ

อ่านขั้นตอนและสิ่งที่ยังต้องตั้งค่า: [AUTO_UPDATE_TH.md](AUTO_UPDATE_TH.md)

## ระบบที่มีโค้ดแล้ว
- **Alpine Linux ARM64 + PRoot** ฝังไฟล์ระบบใน APK แล้วติดตั้งลงพื้นที่ส่วนตัวของแอป
- **Linux Desktop** ใช้ Openbox, XTerm, PCManFM, tint2 และ Xvnc โดยติดตั้งแพ็กเกจกราฟิกจากอินเทอร์เน็ตครั้งแรก
- **ดู Linux Desktop ในแอป** ผ่าน noVNC และให้คอมต่อ VNC ผ่าน Wi-Fi หรือ VPN ส่วนตัว
- **เว็บ AI** บนมือถือและเครือข่ายส่วนตัว พร้อมรหัสผ่าน
- **Local GGUF AI** มีบริการดาวน์โหลด/นำเข้าโมเดล, แชท, SQLite history และ Linux Agent ให้ตรวจแผนก่อนอนุมัติรันคำสั่ง
- **UI Responsive** ปรับหัวแอป, แท็บ, แชท, Linux Agent และ noVNC ให้พอดีกับหน้าจอมือถือและแนวนอน
- **ไม่มี Android Accessibility หรือ MediaProjection** (ไม่สามารถควบคุม Android จาก AI)

## ขั้นตอนเริ่มใช้
1. เปิดแอปและตั้งรหัสผ่านใน Control Center
2. ติดตั้ง Alpine Linux จาก APK
3. โหลดโมเดล AI แบบ GGUF หากต้องการแชท/สั่ง Agent
4. ติดตั้งแพ็กเกจ Linux Desktop ครั้งแรก (ต้องใช้อินเทอร์เน็ต)
5. ตั้งรหัสผ่าน VNC แล้วกดเริ่ม Linux Desktop
6. เปิดหน้าจอ Linux Desktop ภายในแอป หรือให้คอมเปิด VNC Viewer เชื่อมตาม IP และพอร์ตที่แอปแสดง
7. เปิดเว็บ AI จากคอมตามลิงก์ private LAN ที่แอปแสดง

## สิ่งที่ยังไม่เสร็จ
- **ยังไม่ได้ทดสอบ Android 17 E2E จริง** (PRoot, Xvnc, เปิดแอป Linux, รีโมทจากคอม)
- ยังไม่มีระบบ **AI เปิดและควบคุมเว็บเบราว์เซอร์ภายใน Linux อัตโนมัติ**
- ระบบเซ็น APK แบบ **คีย์ถาวร** ยังไม่มีหลักฐานว่าตั้งค่าสำเร็จ: Build แบบ Debug ใหม่อาจติดตั้งทับตัวเดิมไม่ได้
- ยังต้องเพิ่มระบบสำรอง/ย้ายไฟล์ Linux, โมเดล, ความจำ ก่อนถอดแอปเก่า
- Linux installer ยังต้องปรับให้ทนต่อ Android ปิดแอปกลางการติดตั้ง, เพิ่ม progress/notification และ log ที่อธิบายง่าย
- รีโมทผ่าน VNC และ HTTP บน LAN **ไม่มีการเข้ารหัสทราฟฟิก**; ห้ามเปิดพอร์ตสาธารณะ ใช้เฉพาะ Wi-Fi ส่วนตัวหรือ VPN ที่เชื่อถือได้

**อย่าลบแอปรุ่นเก่าหากยังมีไฟล์หรือโมเดลสำคัญโดยไม่ได้สำรองข้อมูล** เพราะชื่อแพ็กเกจหรือลายเซ็นของรุ่นก่อนอาจไม่ตรงกัน

สถานะ: โค้ดและ APK ผ่านการ Build แล้วในรุ่นก่อนหน้า แต่การใช้งานจริงบนมือถือยังต้องพิสูจน์ทีละเกณฑ์
